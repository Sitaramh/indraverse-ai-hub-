INDRAVERSE AI HUB — Starter Website

Files:
- index.html: complete responsive website (HTML, CSS, JavaScript in one file)

Features:
- Mobile-responsive dark UI
- Search and category filters
- 12 sample directory listings linking to official service websites
- Save/favorite tools locally in the browser
- No API keys required for this directory prototype

Important:
- This is a starter directory, not an AI model/service itself.
- Check every listed service's current availability, pricing, age requirements, privacy and terms on its official site.
- No advertising, affiliate tracking, login, payments, or revenue is configured.
- Do not overwrite the existing INDRAVERSE repository/project without making a backup first.

To preview:
Open index.html in a browser.

To publish:
Upload index.html to a new GitHub repository and enable GitHub Pages, or import the folder into a suitable web-building platform. If adding it to an existing repo, back up the original files first and choose the intended folder/path carefully.
